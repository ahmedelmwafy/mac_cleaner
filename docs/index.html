SPEED UP YOUR COMPILES

Premium Bento Architecture

Designed with high-level macOS APIs and optimized to delete deep-nested cache directories securely.

Compiler Build Sweeper

MacCleaner targets massive developer workspace folders, identifying deep project-level build folders that standard disk cleaners ignore. Recover gigabytes of storage safely with direct path integrations:

Flutter (build, .dart_tool) React Native / Node.js (node_modules) Xcode (DerivedData) Gradle (caches, transforms-3) Swift Package Manager (.build)

Granular Checks

No black-box sweeps. Inspect individual folders, read exact file paths, examine nested directory structures, and selectively clean target items while leaving configurations safe.

Hidden Files & Dotfiles

Scan arbitrary local folders to detect hidden assets (names starting with dot `.`). Use instant filter buttons to clean system files like `.DS_Store` or `.env` templates.

100% Offline

Executes locally on your Mac. No network calls requested or allowed, ensuring your local code data stays entirely private and un-tracked.

Vibrant HUD Design

Rendered with SwiftUI materials (`VisualEffectView`). Dark mode gradients align beautifully with your wallpapers and system colors.

Swift 6.2 Speeds

Compiled natively to run with negligible memory usage, scanning hundreds of directories recursively in milliseconds.
